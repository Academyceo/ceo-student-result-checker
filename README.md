# CEO Student Result Checker

A responsive student result checker built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. The sample results work without a server.

## Demo teacher login

- Email: `teacher@ceo.edu`
- Password: `ceo123`

Teacher-added results are saved in the current browser's local storage. This demo has no server, shared database, or secure authentication. Do not use it to store real student data or credentials.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.
4. Wait for the Pages deployment to finish. The site URL will appear on the Pages settings screen.

The student records and teacher demo password are part of the public source code. GitHub Pages is a static host; it does not provide private student records or secure teacher accounts.
